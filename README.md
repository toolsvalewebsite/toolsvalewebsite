# ToolsVale

Free browser-based tools for images, PDFs, data and SEO — built after auditing where the popular alternatives break.

**Live at [toolsvale.com](https://toolsvale.com)** · 38 tools · 34 run entirely in your browser · no accounts, no watermarks, no upload queues.

## The idea

Before building any tool, we run the same file through the popular alternatives (Smallpdf, TinyPNG, iLoveIMG, HEIC converters) and write down where the output actually breaks. Those notes become the spec. Every claim on a tool page comes with a test you can run in under a minute.

## How we handle files

34 of 38 tools decode, convert, and re-encode in your browser. There is no upload request to inspect because there is no upload. The 4 tools that need a server say so on the tool card with a stated deletion window.
